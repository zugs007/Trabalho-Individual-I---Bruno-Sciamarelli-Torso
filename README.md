# Trabalho-Individual-I---Bruno-Sciamarelli-Torso
Repositório destinado ao desenvolvimento do trabalho individual I da disciplina Sistemas Computacionais.

Para visualizar o trabalho, existem duas opções:

### Opção 1: Abertura Direta no Navegador
1. Clone ou baixe este repositório para o seu computador
2. Acesse a pasta raiz do projeto
3. Abra o arquivo `index.html` clicando duas vezes sobre ele ou executando-o em um navegador

### Opção 2: Utilizando o Live Server (VS Code)
1. Abra a pasta do projeto no VS Code
2. Baixe a extensão Live Server
3. Clique com o botão direito no arquivo `index.html` e selecione "Open with Live Server"
4. O navegador abrirá automaticamente o projeto no endereço local
